VERBATIM QUOTE:
"DiffuEraser is an open-source video inpainting pipeline combining spatial diffusion priors with temporal motion guidance. Released under Apache-2.0 license."

KEY FACTS:
- Uses latent diffusion architecture for high-frequency detail synthesis
- Requires >= 12GB VRAM for full HD video processing
- Processing speed: ~1.2s per frame on A100 (too slow for free server host CPU)
